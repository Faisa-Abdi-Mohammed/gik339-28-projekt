* Faisa Abdi Mohammed

## Om projektet

Detta projekt utvecklades inom kursen Software Testing på Högskolan Dalarna.

Applikationen är ett enkelt filmsystem där användaren kan:

* visa filmer
* lägga till filmer
* uppdatera filmer
* ta bort filmer

Projektet har fokus på mjukvarutestning och DevOps.

## Tekniker
* Node.js
* Express
* SQLite
* HTML, CSS, JavaScript
* Jest
* Supertest
* GitHub Actions
  
## Köra projektet

Installera beroenden:

npm install


Starta applikationen:

npm start


## Köra tester

npm test
